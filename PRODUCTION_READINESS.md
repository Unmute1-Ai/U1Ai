# Production Readiness

U1AI is an umbrella engineering workspace. A subproject is production-ready only when its own tests, security gates, deployment documentation, and evidence pass.

For AEGIS-Q specifically:
- [ ] Merge reviewed v0.1 source
- [ ] CI passes
- [ ] TensorRT/Jetson runtime tested on target hardware
- [ ] cuPQC integration independently verified
- [ ] Model artifact provenance/digests pinned
- [ ] AuthorityBench-Embodied evidence published
- [ ] Physical effects remain simulation-only until separately authorized
- [ ] Public demo deploy verified
